# Hero art

Drop official/menu art here as `<hero id>.png` (for example `spider-man.png`, `jeff-the-land-shark.png`,
`bruce-banner.png`). Then run `npm run build:heroes` so `shared/fighters.json` picks it up.

Until a hero has an image, the site shows a type-colored badge with the hero's initials.
Hero ids are listed in `shared/fighters.json` (`"id"`).
